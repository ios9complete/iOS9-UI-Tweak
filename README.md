# iOS9 UI Tweak - UIコンポーネント集

Logos を使用した iOS 9 向け UI カスタマイズコンポーネントのコレクションです。

## 📱 概要

このリポジトリは、iPhone の **Selio** アプリで直接利用できる iOS 9 UI コンポーネント集です。iOS 9 の UI をカスタマイズするための Logos ベースのコンポーネントを提供しています。

## 🎨 主な機能

- iOS 9 UI コンポーネントのカスタマイズ
- Logos ベースの実装
- Selio での直接利用に対応
- モバイルフレンドリーなコード構成

## 📲 Selio での使用方法

### URLで直接追加

以下の URL を Selio アプリにコピー&ペーストして追加してください：

```
https://github.com/ios9complete/iOS9-UI-Tweak
```

### Selio アプリからの検索

Selio アプリ内で以下のキーワードで検索できます：

- `ios9`
- `ui-component`
- `tweak`
- `customization`

## 🛠 対応環境

- **プラットフォーム**: iOS
- **最小バージョン**: iOS 9.0
- **言語**: Logos

## 📦 コンポーネント

各 UI コンポーネントは以下の構造で実装されています：

- Logos ベースの実装
- iOS 9 互換性確認済み
- Selio で即座に利用可能
